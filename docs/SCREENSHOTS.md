# Screenshots Guide

This guide lists recommended screenshots to capture later for the README, portfolio, resume, LinkedIn, or demo walkthrough.

Do not add screenshots until they are intentionally captured, reviewed, and small enough for the repository.

## Recommended Screenshots

1. **Landing / Candidate Overview**
   - Show the ResumeIQ hero, upload controls, decision-support badge, and first dashboard tab.

2. **Resume Quality**
   - Show writing-quality signals, rewrite suggestions, and structure advice.

3. **Job Match Intelligence**
   - Show ATS estimate, skill match, missing skills, semantic matching, and role-fit signals.

4. **Recruiter Workspace / Batch Ranking**
   - Show batch resume ranking, review status, recruiter notes, and CSV export controls.

5. **Recruiter Copilot**
   - Show local evidence search with resume evidence, job-description evidence, similarity, and chunk labels.

6. **Prompt Builder Preview**
   - Show prompt preview workflow with external GenAI disabled and no external AI call.

7. **Model Transparency**
   - Show prediction explanation, model caveat, model registry, and MLflow sections.

8. **Privacy & Responsible AI**
   - Show privacy-safe mode status, responsible AI notes, and synthetic/demo fairness dashboard.

9. **FastAPI Swagger Docs**
   - Capture `http://localhost:8000/docs` showing the main API endpoints.

10. **GitHub Actions CI Green Run**
    - Capture a successful CI run after tests and Docker checks pass.

11. **Docker Compose Running**
    - Capture terminal or Docker Desktop showing Streamlit and FastAPI services running.

## Capture Tips

- Use realistic but non-sensitive sample resume content.
- Turn privacy-safe display mode on for public screenshots.
- Avoid showing personal contact information.
- Avoid showing API keys, local paths with secrets, or private notes.
- Prefer wide desktop screenshots for GitHub and portfolio pages.
- Keep file sizes small before committing.
