# Screenshot Filenames

Save final reviewed screenshots in:

```text
docs/assets/screenshots/
```

Do not add real screenshots until they are intentionally captured, reviewed, and compressed. Use demo/sample data only. ResumeIQ requires human review, does not currently make external GenAI calls, uses privacy-safe masking as a helpful but not guaranteed full anonymization layer, and is not a final hiring decision system.
