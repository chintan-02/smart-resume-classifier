# LinkedIn Featured Descriptions

Use these short descriptions when adding ResumeIQ to LinkedIn Featured, project posts, or portfolio links.

All public screenshots and demos should use demo/sample data only. ResumeIQ requires human review, does not currently make external GenAI calls, uses privacy-safe masking as a helpful but not guaranteed anonymization layer, and is not a final hiring decision system.

## Version 1 - Concise

ResumeIQ is my AI resume intelligence project that analyzes resumes, compares them with job descriptions, and provides recruiter-friendly review signals. It focuses on decision support, privacy-aware workflows, and explainable resume feedback using demo/sample data for public presentation.

## Version 2 - Technical

ResumeIQ is built with Streamlit, FastAPI, Python, scikit-learn, SQLite/SQLAlchemy, Docker, pytest, GitHub Actions, and MLflow foundations. It combines local ML/NLP, ATS-style scoring estimates, semantic matching, batch review workflows, model transparency, and a safe GenAI prompt preview with external AI disabled.

## Version 3 - Recruiter-Friendly

ResumeIQ analyzes resumes against job descriptions to highlight skills, gaps, resume quality signals, and review-ready insights. It is designed to support more consistent resume review while keeping human judgment at the center.
